【半整活】把百度网盘塞进docker里

发表时间：2025-01-30 阅读： 评论：

前言

以前电脑装上百度网盘之后，总是在我的注册表里到处倒垃圾，右键菜单、explorer到处都能看到，删掉之后还能继续拉，时不时还会自己出错让我不得不重新安装，还有他们抽象的UI设计，真的很烦人。我有一点轻度的赛博洁癖，于是把百度网盘删了装进了 Hyper-V 虚拟机里面，干净了不少，但是不是很方便，每次启动要先去服务里启动 Hyper-V，然后启动虚拟机，输入密码后再进入百度网盘，有点麻烦。前段时间学了 docker 以后，成功把 sagemath 塞进去了(但是没写成 Dockerfile)。现在突发奇想把百度网盘塞进去看看怎么样。事实证明还不错。

P.S:deepseek是这样润色的

以前安装百度网盘客户端后，总会在系统注册表中肆意创建冗余项，右键菜单、资源管理器乃至各种隐蔽角落都充斥着它的痕迹。最令人困扰的是这些残留项如同数字杂草，即便手动清理后仍会不断重生，加上其频繁出现的运行错误和令人费解的UI设计，最终让我这个有轻度数字洁癖的用户决定采取隔离措施。

最初尝试将其封印在Hyper-V虚拟机中，虽然获得了清爽的系统环境，但繁琐的启动流程令人却步：每次都要先启用Hyper-V服务，再启动虚拟机，经过密码验证后才能使用。直到最近接触Docker技术，成功将sagemath容器化后（尽管尚未规范化为Dockerfile），突然灵光一现——何不把百度网盘也装进容器？

实践证明确实可行，现在通过精心配置的容器环境，既保持了宿主系统的纯净，又避免了虚拟机方案的笨重流程，这种平衡数字卫生与实用性的体验着实令人欣喜。

优劣比较

相比于正常情况下的百度网盘，把它塞进docker里有一些不同的使用体验

优点：

  • 有效避免了百度网盘到处扔垃圾
  • 有一些弹窗弹不出来啦
  • 个人感觉 linux 的 UI 更好看一点
  • 把流氓软件囚禁起来感觉很爽

缺点：

  • 网速有所下滑，不过如果没有SVIP的话想必不会有什么感受吧（笑）
  • 不能通过浏览器调用启动百度网盘，也不能用剪贴板下载，必须先转存再下载
  • 买不了会员，因为弹不出浏览器（这算是缺点吗？）

总结

感觉还是挺不错的，临时用用体验很好，不过传输大文件的时候大概还得启动虚拟机。

过几天把 sagemath 整好，我再也不想体验比赛早上九点结束而凌晨三点的我虽已有exp脚本却还在头疼配置sagemath+flatter环境时的疯狂报错了
